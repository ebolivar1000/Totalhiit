# Arquitectura - Proyecto TOTALHIIT

## Concepto del Proyecto
**TOTALHIIT** es una plataforma web y móvil de entrenamiento físico (HIIT de impacto adaptado) y nutrición funcional diseñada específicamente para mujeres de más de 40 años (+40) hispanohablantes a nivel internacional.

## Configuración y Stack Tecnológico

| Componente | Elección | Rol / Detalle |
| :--- | :--- | :--- |
| **Frontend Web** | React + Vite + Tailwind CSS + TypeScript | Web moderna, ultra rápida, responsiva y estilo Framer |
| **Editor** | VS Code | Entorno de desarrollo principal |
| **Agente principal** | OpenCode (v1.19.3) | Agente CLI / TUI interactivo para codificación |
| **IA en la nube** | Gemini CLI / AGY | Modelos en la nube para tareas complejas (Google AI Studio) |
| **IA local** | Ollama (Qwen3 4B / 8B) | Modelos locales rápidos sin cuotas de API |
| **Pasarela de Cobros** | Wise (USD) + Mercado Pago (ARS) | Wise para mujeres fuera de Argentina; Mercado Pago para Argentina |
| **Video Hosting** | YouTube Embeds | Clases del Bootcamp TOTAL+40 organizadas en 4 semanas |
| **Control de versiones** | Git | Repositorio y control de código |
| **Memoria compartida** | `AGENTS.md` + `docs/` | Contexto persistente y alineación entre modelos |
| **Presupuesto mensual** | USD 0 | Stack y modelos sin costos fijos de software |
